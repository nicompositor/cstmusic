# Currículo Vivo de Música · Colegio San Tarsicio

Sitio estático del currículo de Música de Prejardín a Quinto. Incluye planeador semanal, navegación por grado, herramientas docentes y un mapa STEAM/transdisciplinar conectado con cada bimestre. No necesita instalación, servidor especial ni proceso de compilación.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube **todo el contenido de esta carpeta** a la raíz del repositorio.
3. En el repositorio, abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main`, carpeta `/ (root)` y pulsa **Save**.
6. GitHub mostrará la dirección pública cuando termine la publicación.

## Archivos principales

- `index.html`: estructura de la página.
- `styles.css`: diseño adaptable para computador, tableta, celular e impresión.
- `app.js`: navegación, filtros, notas locales y planeaciones.
- `curriculum-data.js`: contenido completo de preescolar y primaria.
- `downloads/`: documentos editables originales.

Las marcas de “clase preparada” y las notas del profesor se guardan únicamente en el navegador del dispositivo mediante almacenamiento local.
